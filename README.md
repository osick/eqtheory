# eqtheory (planned)

A Python library for equational theories over magmas: term rewriting with
a Knuth–Bendix order, proof-producing e-graph saturation, goal-directed
superposition, finite and infinite countermodel search, and Lean 4
certificate generation — the algorithms of the SAIR Stage-2 solver as a
package. Plan: `../docs/plans/2026-09-01-eqtheory-lib-plan.md`.

This directory is laid out as a future standalone repository.
